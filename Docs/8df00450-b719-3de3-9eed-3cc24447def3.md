# Swimming Pools and the ENERGY STAR Score in the United States and Canada

## Overview
*The ENERGY STAR score provides a fair assessment of a property's energy performance relative to its peers, considering climate, weather, and business activities. While stand-alone swimming pools are not eligible for an ENERGY STAR score, adjustments are made for pools that are energy-intensive amenities in other commercial building types (e.g., hotels, schools). The goal is to rate the primary use of the building, not the swimming pool itself.*

### Technical Approach
*   An **engineered model** estimates energy use for the swimming pool.
*   This estimated energy use is **subtracted** from the buildings actual energy use.
*   This allows the building to be evaluated as if it does not have a pool.

### Property Types
*   Heated swimming pools (indoor or outdoor) are incorporated into the ENERGY STAR score for eligible property types.
*   No calculations or adjustments are made for unheated pools, as heated pools consume significantly more energy.

### Adjustments
The swimming pool model is based on engineered assumptions regarding basic energy requirements and includes:
*   **Heating Energy**: Accounts for maintaining a constant temperature against heat loss (convection, evaporation, radiation).
*   **Pumping Energy**: Accounts for energy used to circulate pool water.

### Release Date
*   **Most Recent Update**: August 2023
*   **Original Release**: January 2004

## Theoretical Background
*The engineered model to predict pool energy use is based on the fundamental rules of physics involved in heated pools and their interaction with the surrounding space.*

**Total Energy Consumed by a Heated Pool** is the sum of pool heating energy consumption and pool pump electrical energy consumption.

**Heat Loss from a pool includes** evaporation loss, convection loss, long wave radiation loss to cold sky, and conduction through lateral surfaces to the ground. For outdoor pools, heat loss is offset by heat gains due to solar irradiation.

### Model Assumptions
*   **Indoor Pool Heating**: Only evaporation and convection are significant heat loss contributors.
*   **Outdoor Pool Heating**: Evaporation, convection, and radiation are significant heat loss contributors.
*   **Conduction Losses**: Ignored due to small impact.
*   **Temperature**: Pools operate at a fixed temperature year-round.
*   **Make-up Water Heating**: Ignored.
*   **Convection**: A fixed convection heat transfer coefficient is used.
*   **Source Energy**: Assumes natural gas for heating and electricity for pumping. Conversions from site to source energy are applied based on the country (U.S. or Canada). *Footnote 1: The pool adjustment was revised in 2018 for U.S. properties, and in 2023 for Canadian properties, to account for updated ratios used in Portfolio Manager to convert site energy to source energy.*
*   **Equation Inputs**: Fixed values are used for most variables to minimize user inputs, based on engineering judgments and parametric sensitivity analysis.

## Outdoor Pool
*Calculating energy consumption for outdoor pools is more complex due to greater variability in input parameters like wind speed, water temperature, air temperature, relative humidity, solar radiation, and operating hours.*

*A parametric sensitivity analysis was conducted across different locations (e.g., Boston, Miami) and operating seasons. Due to the wide range of energy consumption estimates, sub-metering outdoor pools is recommended to accurately track energy use and exclude it from Portfolio Manager.*

*If sub-metering is not possible, Portfolio Manager will apply a conservative estimate for outdoor pool energy consumption based on minimum adjustments from the sensitivity analysis. This estimate is less accurate than sub-metering.*

## Example Calculation
*This example demonstrates the five steps to compute an ENERGY STAR score for a U.S. school with a swimming pool.*

### 1. User enters building data into Portfolio Manager
*   12 months of energy use information (annual values, monthly meter entries).
*   Physical building information (size, location) and use details (hours, etc.).

**Summary of Energy Data**

| Energy Data | Value |
| :---------- | :---- |
| Electricity | **800,000 kWh** |
| Natural Gas | **30,000 therms** |

**Summary of Property Use Details**

| School Property Use Details | Value |
| :-------------------------- | :---- |
| Gross Floor Area (ft<sup>2</sup>) | **100,000** |
| High School | **1 (Yes)** |
| Open weekends | **1 (Yes)** |
| Number of workers | **70** |
| Presence of cooking | **0 (No)** |
| Percent of the building that is heated | **100** |
| Percent of the building that is cooled | **100** |
| HDD (provided by Portfolio Manager, based on Zip code) | **4,937** |
| CDD (provided by Portfolio Manager, based on Zip code) | **1,046** |
| **Swimming Pool Use Details** | **Value** |
| Pool Size | **Short Course** |
| Pool Location | **Indoor** |
| Property Type (Set by Portfolio Manager based on use types entered) | **K-12 School** |

### 2. Portfolio Manager computes the actual source EUI
*   **Billed Source Energy** is computed by converting fuel units to site and then source energy, then summing.

**Computing Actual Source EUI**

| Fuel | Billings Units | Site kBtu Multiplier | Site kBtu | Source kBtu Multiplier | Source kBtu |
| :--- | :------------- | :------------------- | :-------- | :--------------------- | :---------- |
| Electricity | 800,000 kWh | 3.412 | 2,729,600 | 2.80 | 7,642,880 |
| Natural Gas | 30,000 therms | 100 | 3,000,000 | 1.05 | 3,150,000 |
| **Total Source Energy** | | | | | **10,792,880 kBtu** |

*   **Predicted Pool Energy** is determined using **Figure 3**: For an Indoor, Short Course Pool at a K-12 school in the U.S. = **2,084,866 kBtu**.
*   **Actual Source energy** for the ENERGY STAR score = Billed Source Energy - Predicted Pool Energy = **10,792,880  2,084,880 = 8,708,000 kBtu**.
*   **Actual Source EUI** = Source Energy / Total Floor Area = 8,708,000 kBtu / 100,000 ft<sup>2</sup> = **87.08 kBtu/ft<sup>2</sup>**.

### 3. Portfolio Manager computes the predicted source EUI
*   Using property use details, Portfolio Manager calculates building variable values for the regression model.
*   Centered variables are multiplied by coefficients from the Office regression equation to obtain a predicted source EUI.

**Computing Predicted Source EUI**

| Variable | Actual Building Value | Reference Centering Value | Building Centered Variable | Coefficient | Coefficient * Centered Variable |
| :------- | :-------------------- | :------------------------ | :------------------------- | :---------- | :------------------------------ |
| Constant | -- | -- | -- | 101.7 | **101.7** |
| High School | 1.000 | -- | 1.000 | 14.08 | **14.08** |
| Open Weekends (yes/no) | 1.000 | -- | 1.000 | 15.66 | **15.66** |
| Number of Workers per 1,000 ft<sup>2</sup> | 0.7000 | 0.7967 | -0.09670 | 25.61 | **-2.476** |
| Presence of Cooking (yes/no) | 0.000 | -- | 0.000 | 8.182 | **0** |
| HDD x Percent Heated | 4,937 | 3,597 | 1,340 | 0.008370 | **11.22** |
| CDD x Percent Cooled | 1,046 | 1,472 | -426 | 0.02059 | **-8.771** |
| **Predicted Source EUI (kBtu/ft<sup>2</sup>)** | | | | | **131.4** |

### 4. Portfolio Manager computes the energy efficiency ratio
*   Ratio = Actual Source EUI (Step 2) / Predicted Source EUI (Step 3)
*   Ratio = **87.08 / 131.4 = 0.6627**

### 5. Portfolio Manager uses the efficiency ratio to assign a score via a lookup table
*   Using the ratio of **0.6627** and the lookup table for schools (not provided in this document).
*   **The ENERGY STAR score is 81**.
